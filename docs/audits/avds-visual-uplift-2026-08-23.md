# ShadowBroker AVDS visual uplift — deployed baseline and final local candidate

Date: 2026-08-24. AVDS `4.7.0` remains represented by a static semantic adapter
in this checkout; it is not a package-consumption claim.

## Applied composition

The public map retains map layers, search, filters, news and a truthful service
state. It removes operator, AI, market and configuration controls before they
render. The Time Machine surface explains that recorded snapshots belong to the
local operator runtime; private layers are absent rather than presented as
enabled controls that fail.

The deployed `ef6…` baseline had matching AVDS edge metadata and browser proof
of no `MKT`, System Settings or Operator controls at `390x844`. The browser also
found hydration error `#418`, so it is not accepted as the final AVDS release.

`809271c` adds the missing build-time public-mode declaration. It passes the
local production build and all 818 frontend tests. The final mobile and desktop
browser rerun is deferred solely by the active Hostinger CPU restriction on the
excluded runtime host; no remote process remains active.
